VELMORA — a travel poster for a place that isn't there. A city of floating
islands above a sea of clouds, with a lighthouse, a waterfall pouring into
the sky, and a low sun setting behind it all. The poster is drawn from
scratch by `main.py` (pure Python 3 standard library: no network, no
external assets, no fonts on disk — the scene uses a small software
rasterizer and a hand-drawn vector stroke font), and written to
`/output/entry.png` (800×1024, ~170 KB, deterministic across runs).

## Run it

```sh
python3 main.py
```
